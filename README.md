# Колодец 3D

3D-просмотрщик сборных железобетонных колодцев канализации (К1) и водопровода (В1) для паспорта сборки KOLSB.

Страница открывается по QR-коду из паспорта: данные колодца передаются внутри ссылки (после `#`) и на сервер не отправляются.
Без ссылки страница предлагает «Показать пример».

## Как пользоваться

- Повернуть — тянуть пальцем или мышью; приблизить — двумя пальцами или колесом.
- **▶ Сборка** — анимация сборки в том же порядке, что шаги паспорта: ❚❚ — пауза, ⏮ / ⏭ — шаг назад / вперёд,
  1× — скорость, ✕ — закончить (на компьютере: пробел, ← / →, Esc). Битум наносят кистью снизу вверх; набетонку
  горловины — в опалубку из ведра, верх заглаживают кельмой, потом опалубку снимают.
- **Как собрать** — те же шаги по одному (◀ / ▶).
- **Разрез**, **Разобрать** (разнесённый вид), **Изнутри** — вид из колодца: «Люк», «Углы», «Сверху», ▲ / ▼ — вверх и вниз по скобам.
- **Раскладка** (прямоугольные В1) — перекрытие строго сверху, как на чертеже: номер и марка на каждой плите, балки Б8
  под плитами — пунктиром, люки, размеры снаружи и в свету. Нажмите на плиту — её размеры и масса; **Вид** — выйти.
- **Гидроизоляция**, **Покрытие** (газон, тротуар, дорога), **Подписи** — показать или скрыть; **Вид** — вернуть исходный вид;
  ◐ — светлая или тёмная тема.
- Подписи стоят слева и справа от колодца, каждая на высоте своего элемента. Нажмите на подпись или на сам элемент —
  он подсветится (разгорается, светится, чуть тускнеет и снова разгорается), остальное станет полупрозрачным;
  ещё раз или по пустому месту — снять.
- Грунтовые воды — две плоскости вокруг колодца: пурпурная — ожидаемый (максимальный, с паводком) уровень, по нему
  гидроизоляция; синяя — установившийся.
- **Данные** — состав колодца, условия, проверка и «Цвета на модели».
- Бетон на модели — с лёгкой зернистостью, как у настоящего. Посмотреть без неё — `?grain=0` в адресе перед `#`
  (например `…/kolsb-3d/?grain=0#…`).

## Файлы

- `index.html` — страница просмотра
- `core.js` — модель колодца К1, лоток, МС, шаги сборки
- `corevv.js` — водопроводные колодцы В1: круглые и прямоугольные (ТПР 901-09-11.84)
- `vendor/` — three.js r128 (MIT, см. `vendor/LICENSE.three`)

Файлы собираются из исходников пакета KOLSB вместе с паспортом сборки (`kolsb_passport.html`), поэтому модель и шаги
на сайте и в паспорте одни и те же. Здесь их вручную не правят.

Демонстрационная версия.
